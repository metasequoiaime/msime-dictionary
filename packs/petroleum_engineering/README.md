# 石油工程专业词库

面向石油工程与油气开发科研、工程人员的可选词库，覆盖油气地质与储层评价、油藏工程、钻井与完井工程、采油采气工程、提高采收率、非常规油气开发、油藏数值模拟、分子模拟与界面科学八个方向的专业术语。词库以多字专业术语、专有名称和领域缩写为主，包含中文候选、保留官方大小写的英文候选，以及中英双向术语释义。其中油藏数值模拟部分收录了商业求解器（IMEX 黑油、GEM 组分、STARS 热采与化学）实际使用的控制方程、相平衡与状态方程、离散化与线性求解方法，以及井流、反应动力学与地质力学耦合方程。

## 导入

在水杉输入法设置的词库管理页面中：

1. 选择拼音词库的“编码导入”，导入 `quanpin.txt`。
2. 选择英文词库的“导入”，导入 `english.txt`。

中文文件使用 `词语<Tab>全拼<Tab>权重`，英文文件使用 `输入键<Tab>显示内容<Tab>权重`。两个文件故意不含标题或注释，避免设置程序把说明文字当作词条。当前中文候选 1451 条、英文候选 199 条，另附完整的术语对照。

`translations.txt` 是术语对照审校稿，前半部分是中文候选到英文术语，后半部分是英文候选到中文释义，覆盖上面两个文件里的全部候选。`MD`、`MC`、`MM`、`PI`、`GL`、`SP`、`SW`、`SO`、`SG`、`TD`、`BU`、`PL`、`SRP`、`SOR`、`DTP` 等短缩写在其他领域另有含义，只保留在本专业包中，不同步到 `custom/translations.txt`。

## 收录原则

- 只收录石油工程各分支里实际会输入的术语，不收句子和定义；人名只收公共人物。
- 不收已在发布拼音词库（`sources/pinyin/rime-ice.txt`、`sources/pinyin/rime-ice-supplement.txt`、`sources/pinyin/places.txt`、`custom/words.txt`）中出现的词，不论读音是否相同；“碳酸盐岩”“采收率”“井筒完整性”“水力压裂”一类已进入通用词库的词不再重复收录（对照后去重 206 条）。
- 油藏数值模拟部分除常规模拟术语外，收录求解器使用的计算方程与数值方法：控制方程（质量守恒方程、动量守恒方程、能量守恒方程、达西方程、对流扩散方程、热传导方程）、相平衡与状态方程（闪蒸方程、泡点方程、露点方程、逸度平衡方程、立方型状态方程、体积平移）、离散与求解方法（牛顿迭代法、雅可比矩阵、隐式压力显式饱和度、全隐式方法、自适应隐式方法、预处理共轭梯度法、广义最小残差法、正交极小化法、代数多重网格法、不完全分解、嵌套分解法）、约束与物性关系（体积约束方程、饱和度约束方程、相压力约束方程、传导率、分流量方程、贝克莱列维莱特方程），以及井流、反应动力学与地质力学耦合方程。方程名与英文写法取自 CMG 用户手册与油藏数值模拟教材，只记录名称，不抄录公式。
- 中文候选权重统一为 10000，英文候选权重统一为 10，与 `ai_ml`、`unreal_houdini` 一致。
- 英文候选的显示内容采用项目或软件官方写法（`ECLIPSE`、`tNavigator`、`Petrel`、`LAMMPS`、`GROMACS`、`PLUMED`、`OVITO`、`VMD`），输入键只含小写字母和连字符；`CO2 EOR` 的输入键写作 `carbon-dioxide-eor`，`QM/MM` 写作 `qm-mm`，`Nose-Hoover` 写作 `nose-hoover`。
- 相近或在文献中成对使用的术语一并收录，例如“孔喉结构 / 孔隙结构”“可采储量 / 控制储量”“采液指数 / 采油指数”。
- 只收领域里实际会输入的多字术语、专名与缩写；单字词（油、气、井、压力、温度）和已在通用词库中的常见双字词不收。
- 不复制术语库或文档的定义正文，只记录术语和短释义。

## 多音字

以下字按所在术语逐条核对过读音（对照 `sources/pinyin/single-chars.txt` 与 `sources/pinyin/rime-ice-supplement.txt` 的单字行）：

- 率：读 `lv`，用于绝对渗透率、递减率、返排率、含气率、造斜率、井眼曲率等全部含“率”的术语。
- 藏：读 `cang`，用于油藏工程、凝析气藏、定容气藏、页岩气藏、埋藏史等。
- 相：读 `xiang`，用于相对渗透率、相渗曲线、油水两相流、多相流、混相、非混相驱、相态拟合等。
- 混：读 `hun`，用于混相、混相驱、最小混相压力、混砂车。
- 石：读 `shi`，用于金刚石钻头、伊利石、砾石充填、岩石压缩系数。
- 系：读 `xi`，用于沉积体系、含油气系统、表皮系数、系综。
- 重：读 `zhong` 用于重力驱、重力分异、重力超覆、加重钻杆、重矿物、重馏分表征；读 `chong` 用于重复压裂、重复压裂时机、双重介质模型、双重介质模拟、多重介质、多重运移机制、代数多重网格法。
- 长：读 `chang`，用于长岩心驱替、长水平段、长时间尺度、长程静电、长程修正、缝长、键长、时间步长、时间步长控制。
- 卡：读 `ka`，用于卡钻、解卡、砂卡、蒙特卡洛模拟、集合卡尔曼滤波、卡门科泽尼方程。
- 干：读 `gan`，用于干酪根、干酪根类型、干气驱、干扰试井、井间干扰、段间干扰。
- 调：读 `tiao`，用于调剖、深部调驱、凝胶调驱、调驱剂、调驱体系。
- 塞：读 `sai` 用于桥塞、段塞流、柱塞气举、水力活塞泵、扫塞、钻塞；读 `se` 用于水合物堵塞。
- 剖：读 `pou`，用于调剖、吸水剖面、产液剖面、产出剖面、注入剖面。
- 行：读 `hang` 用于行列注水；读 `xing` 用于相态行为、大规模并行、平行层理。
- 应：读 `ying`，用于应力敏感、地应力剖面、应力各向异性、应变监测、响应面。
- 场：读 `chang`，用于力场参数、全原子力场、压力场、优势流场。
- 曲：读 `qu`，用于曲流河、相渗曲线、井眼曲率。
- 冲：读 `chong`，用于冲次、冲程损失、冲刷面。
- 薄：读 `bao`，用于薄片鉴定。
- 色：读 `se`，用于色谱效应、色散修正。
- 泊：读 `po`，用于泊松方程。
- 落：读 `luo`，用于落鱼、均方根涨落。
- 粘：读 `nian`，用于原油粘度、粘性指进、粘土含量、粘土稳定剂（“粘”与规范的“黏”同音，本包按通行写法收录“粘”）。
