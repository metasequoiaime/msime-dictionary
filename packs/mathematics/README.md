# 数学专业词库

面向数学专业学习和写作的可选词库，覆盖集合论与数理逻辑、群论、环域与模、线性代数、范畴论与同调代数、拓扑、微分几何、李理论与表示论、代数几何、实分析与测度论、复分析、泛函分析、微分方程与动力系统、数论、概率论与随机过程、组合与图论等方向的术语。当前包含中文候选、带变音符号和官方大小写的英文候选，以及中英双向术语释义。

## 导入

在水杉输入法设置的词库管理页面中：

1. 选择拼音词库的“编码导入”，导入 `quanpin.txt`。
2. 选择英文词库的“导入”，导入 `english.txt`。

中文文件使用 `词语<Tab>全拼<Tab>权重`，英文文件使用 `输入键<Tab>显示内容<Tab>权重`。两个文件故意不含标题或注释，避免设置程序把说明文字当作词条。

`translations.txt` 是完整的术语对照审校稿，前半部分按方向分组列出中文候选到英文术语，后半部分是英文候选到中文释义。本包没有向 `custom/translations.txt` 同步条目。

## 收录原则

- 只收录数学本科到研究生阶段实际会输入的术语、定理名和对象名，不收句子和定义。
- 不收已在发布拼音词库（`sources/pinyin/rime-ice.txt`、`sources/pinyin/rime-ice-supplement.txt`、`sources/pinyin/places.txt`、`custom/words.txt`）中出现的词，不论读音是否相同；例如“群论”“同调”“上同调”“范畴论”“流形”“同胚”“纤维丛”“拉回”“推出”“勒贝格测度”“傅里叶级数”都已在发布词库中。
- 同一概念有多个通行译名时并列收录，例如“稳定子 / 稳定化子”“外微分 / 外导数”“数量曲率 / 标量曲率”“磨光算子 / 磨光子”“检验函数 / 试验函数”“海森矩阵 / 黑塞矩阵”“正向极限 / 直极限”“对偶范畴 / 反范畴”“共形映射 / 保角映射”“标准正交基 / 规范正交基”“简化剩余系 / 既约剩余系”“一般点 / 泛点”。
- 中间带连字符或间隔号的人名组合（如“哈恩-巴拿赫定理”“柯西-黎曼方程”“冯·诺依曼代数”）暂不收录：中文资料里连字符与间隔号的写法不统一，拼音也无法覆盖这些符号。含拉丁或希腊字母的术语（如 p 进数、L 函数、σ 代数）同样不收，因为中文候选要求汉字数等于拼音音节数；σ 代数收了“西格玛代数”这一写法。
- 英文候选只收发布英文词库（`sources/english/rime-ice-en.txt`、`sources/english/rime-ice-en-supplement.txt`、`sources/english/scowl-words.txt`、`custom/english.txt`）中没有同样写法的词；`functor`、`sheaf`、`homology`、`isomorphism`、`Hausdorff`、`Lebesgue`、`Galois`、`Riemann`、`Hilbert` 等已有，不重复收录。
- 带变音符号的人名，英文候选显示原文写法，输入键去掉变音符号（`kahler` → `Kähler`，`cech` → `Čech`，`poincare` → `Poincaré`，`erdos` → `Erdős`）；德语变音另收 `ae`、`oe`、`ue` 转写的输入键（`kaehler`、`goedel`、`groebner`、`schroedinger`、`moebius`、`kuenneth`、`hoelder`、`loewenheim`），两种键给出同一个显示内容。
- 英文大小写：形容词按数学写作习惯小写（`abelian`、`étale`、`holomorphic`、`semisimple`），由人名派生、习惯上大写的保留大写（`Noetherian`、`Artinian`、`Riemannian`）。
- `translations.txt` 的英文释义用标题式大小写；人名定理按英文通行写法（`Zorn's Lemma`、`Seifert-van Kampen Theorem`、`Banach-Steinhaus Theorem`）。
- 中文候选权重统一为 10000，英文候选权重统一为 10，与 `ai_ml`、`unreal_houdini` 一致。
- 不复制教材或术语库的定义正文，只记录术语和短释义。

## 多音字

以下字按所在术语逐条核对过读音：

- 行：`hang` 用于行空间、行秩、行阶梯形、简化行阶梯形，以及范德蒙德行列式、朗斯基行列式、雅可比行列式；其余如线性、流形、平行移动读 `xing`。
- 重：`chong` 用于多重线性映射、多重线性代数、多重图、重心重分中的“重分”、黎曼重排定理；重心读 `zhong`。
- 调：`diao` 用于同调及其派生词（同调群、上同调群、奇异同调、层上同调、平展上同调等）和单调收敛定理、单调类定理、单调有界定理；`tiao` 用于调和函数、次调和函数、调和形式。
- 长：长正合列读 `chang`。
- 率：曲率类术语、挠率、概率类术语读 `lv`；定律、互反律、零一律的“律”也读 `lv`。
- 度：测度类术语（外测度、测度空间、乘积测度、拉东测度、哈尔测度、豪斯多夫测度、依测度收敛等）读 `ce'du`。万象词库把这些词标作 `ce'duo`（“揣度”义），与数学含义不符，这里不采用。
- 泊：泊松流形、泊松方程读 `bo`。
- 伽：伽罗瓦扩张、伽罗瓦群、伽罗瓦对应同时收 `jia` 和 `ga` 两种读音：发布词库的“伽罗瓦”“伽罗瓦理论”读 `jia`，万象词库的“伽罗瓦”“伽罗瓦群”读 `ga`，两种读法都通行。伽马函数、伽马分布读 `ga`。
- 勒：勒贝格、勒让德、凯勒读 `le`。
- 和：和乐群读 `he'le`；直和、楔和、连通和、黎曼和、达布和、高斯和读 `he`。
- 奇：奇异同调、奇异测度、孤立奇点、可去奇点、本性奇点、奇点消解、奇怪吸引子，以及人名霍奇、里奇读 `qi`。
- 卡：卡积、坐标卡、皮卡群、皮卡迭代、卡蒂埃除子、卡方分布、笛卡儿积、卡西米尔元读 `ka`。
- 角：对角化、三角矩阵、三角范畴、辐角原理、保角映射读 `jiao`。
- 系：剩余系、线性系、万有系数定理、哈密顿系统、可积系统读 `xi`。
- 差：变差、全变差、二次变差、大偏差原理、有限差分法、符号差读 `cha`。
- 塞：塞尔对偶、帕塞瓦尔恒等式、贝塞尔函数、黑塞矩阵读 `sai`。
- 着：图着色读 `zhuo`。
- 拓：拓扑类术语读 `tuo`。
- 纤：纤维类术语读 `xian`。
- 柏：柏拉图立体读 `bo`。
- 迫：力迫法读 `po`。
- 扎：扎里斯基拓扑读 `zha`。
- 拆：整数分拆读 `chai`。

## 核对来源

### 读音（核对于 2026-11-02）

读音由三个来源交叉比对，不一致处和上面列出的多音字逐条人工审定：

- 本仓 `sources/pinyin/wanxiang/` 下的万象词库（amzxyz/rime-wanxiang，CC BY 4.0，见 `NOTICE.md`）：1130 个词里有 646 个收在万象词库中，其中 639 个与本包读音一致；不一致的 7 个是“行空间”和 6 个测度类术语，原因见上文多音字一节。其余 484 个词万象词库没有。
- 发布拼音词库（`sources/pinyin/rime-ice.txt` 等）：按最长匹配把词切成发布词库已有的词，取这些词的读音，例如“伽罗瓦”“勒贝格”“凯勒”“伽马”。
- [pypinyin](https://github.com/mozillazg/python-pinyin) 0.55.0 的 `lazy_pinyin`：它把伽罗瓦读成 `ga`、泊松读成 `po`、勒贝格和勒让德读成 `lei`、凯勒读成 `kai'lei`、外测度读成 `ce'duo`、行空间和行秩读成 `xing`、长正合列读成 `zhang`、多重读成 `zhong`，这些都没有采用。

每个字的读音还经过 `scripts/validate_packs.py` 对照 `sources/pinyin/single-chars.txt` 与 `sources/pinyin/rime-ice-supplement.txt` 单字行的检查。

### 无官方中文出处的术语

本包的全部术语都按国内数学本科与研究生教材里的通行说法收录，没有逐条对应到单一来源；人名译法采用教材常见写法（若尔当、埃尔米特、豪斯多夫、诺特、阿廷、伽罗瓦、嘉当、外尔、索伯列夫）。整理时没有访问术语在线（全国科学技术名词审定委员会）或《数学名词》逐条核对规范名，审阅时可以以它们为准提出修改。
